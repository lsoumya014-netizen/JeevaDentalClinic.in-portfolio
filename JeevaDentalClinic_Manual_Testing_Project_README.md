Jeeva Dental Clinic Website – Manual Testing
Project Overview
This project demonstrates manual testing performed on the Jeeva Dental Clinic website.
The objective was to validate homepage, navigation, booking, enquiry, review, emergency triage, payment flows, and accessibility across desktop and mobile devices.

Application Under Test
Application: Jeeva Dental Clinic Website
Technology: Web (HTML, CSS, JavaScript, backend booking/payment modules)
Testing Type: Manual Testing

Testing Performed
Smoke Testing – Homepage load, navigation, blog, service CTAs

Sanity Testing – Smile Studio filters, assets, payment actions, confirmation copy

Functional Testing – Appointment booking, enquiries, reviews, emergency triage, payments

UI Testing – Layout, responsiveness, typography, images, modals, forms

Frontend Testing – Hash navigation, browser history, JS fallback, caching, console/network behavior

Accessibility Testing – Keyboard navigation, screen reader labels, zoom/reflow, error announcements

Security Testing – XSS inputs, sensitive data handling, duplicate/rate limits, storage checks

Performance Testing – Page load, image optimization, repeated filters, modal resilience

Regression Testing – Critical workflows after updates

Project Outcome
The project provided practical experience in end-to-end manual testing of a healthcare website.
It validated booking, enquiry, review, emergency triage, and payment workflows, identified critical defects (broken QR, placeholder actions, inconsistent branding/pricing), and strengthened skills in functional, UI, accessibility, security, and performance testing.
